# 小五趣味數學：校本靜態網站（初稿）

給香港小學教師課堂使用。全繁體中文、免登入、不需後端、可離線開啟。約 20 名小五中等／中下能力學生、二人一機、iPad Safari 單指觸控。每節 50 分鐘。

本網站對齊教案《小五趣味數學六節方案》，是自製校本版，不是外站連結頁。

## 如何開啟

**方法一：用檔案直接打開（file://）**

1. 把整個 `p5-fun-math-site` 資料夾複製到 iPad 或電腦。
2. 用 Safari（iPad 可在「檔案」選 `index.html`，再分享 → 用 Safari 開啟）打開總覽頁。
3. **不要只在對話、電郵或雲端的預覽畫面觀看 HTML**，否則遊戲不會執行，地圖也可能是一片空白。

**方法二：本機靜態伺服器**

在電腦的 `p5-fun-math-site` 目錄執行：

```bash
python3 -m http.server 8765
```

然後用瀏覽器打開 `http://127.0.0.1:8765/`（同一 Wi-Fi 下的 iPad 可改用該電腦的區域網絡 IP）。

本網站不使用外部 CDN 或網路字體，沒有網絡也能玩。

## 對應學習目標與操作

**第 1 節　密碼解碼員**  
學生頁學習目標：我能夠發現和運用規律，把資料按規則轉換，再按相反方向還原。  
學生頁任務目的：① 用一個移位數字，把一個英文字變成秘密暗號。支援層不用自己選，已鎖定為 +3。② 用同一個數字，把暗號變回原來的字。也可以和同學交換暗號再互變。兩項都做對一次，就算完成。只用英文字母，不要用中文。  
明白加密／解密，用同一把鑰匙（移位格數）親手把明文變成密文，再還原。預設鑰匙 +3（支援層鎖定）。練習須先自己填再核對，不會一邊輸入一邊自動給答案。沒有「試遍 25 種移位」功能。只處理 26 個大寫拉丁字母；輸入漢字會清楚提示。建議橫向。豬圈只在挑戰層作延伸。交換密文（二人一機）時，同學 A 核對暗號正確後須按「遮住，交給同學 B」，原字會從畫面、輸入框及其他分頁清走，只留下暗號和鑰匙；挑戰層可選「不顯示鑰匙（未知鑰匙）」。同學 B 核對答對才計「解密一次」，按「揭曉」可看原字但不計入進度。可按「重新開始」換角色。

**第 2 節　老實人與大話王**  
學生頁學習目標：我能夠用有系統的方法推理：逐一假設，檢查會不會說不通，找出唯一答案。  
學生頁任務目的：① 先假設誰是老實人（永遠說真話）、誰是大話王（永遠說假話）。每個人都可能是其中一種，人數沒有限制，可以全部都是老實人，也可以全部都是大話王。② 根據他們說的話，檢查這個假設說不說得通。說得通的那一組，就是這題的答案。  
老實人永遠說真話，大話王永遠說假話。先做一人一句，再做兩人題；挑戰才出現互相指稱，並可出題給鄰組（會檢查是否只有一個答案）。提示只引導「先假設、再看說不說得通」，不直接公布答案。沒有三人群題作為起步。

**第 3 節　終極密碼**  
學生頁學習目標：我能夠根據線索，有系統地排除不可能的答案，逐步縮窄範圍。  
學生頁任務目的：① 猜出這組秘密數字。支援層是 3 個位置，只可用 1、2、3、4。② 每次提交後會看到 A（數字和位置都對）和 B（數字對，但放錯位置）。看著紀錄再猜下一次。③ 全部位置都對，就算完成。  
預設 3 位、不重複；有猜測紀錄。支援層只用 1–4；挑戰可改 4 位、允許重複或自我限制 5 次。沒有限時，沒有一鍵公布整個答案。

學生可自行開關五項「提示工具」（預設全部關閉，開啟不扣分）：（1）A／B 意思提示，重溫定義並附例子；（2）數字排除板，由學生自己把數字標記為「一定有／一定沒有／未知」，系統不自動填；（3）可能答案數目，只顯示還剩多少種可能，不列出答案（不再一開始就顯示）；（4）紀錄比較提示，把新猜測和上一次或選定的一次紀錄相比，只標示不同的位置或數字，不判斷對錯；（5）揭示一個位置，每局只限一次、先確認再看其中一位，挑戰層建議先不用。完成一局時會中性註明「本局用了：…」。支援層可鼓勵先開（1）（2）；挑戰層建議少用（5）。

**第 4 節　信任的進化**  
學生頁學習目標：我能夠運用得分表比較不同選擇的結果，作出有根據的決定。  
情景是「小食交換」：每人有一包薯片（或其他小食）。兩位同學各自按藏選擇「🤝 分一半」（把一半分給對方）或「😋 自己食」（自己食掉那包小食），兩人都選完才一起揭曉。選項用日常情景詞，學生畫面寫明「選哪一個都可以，沒有對錯」，不評價誰好誰壞。

學生畫面任務目的：『① 和同學玩「小食交換」。每輪各自選「分一半」或「自己食」，先藏起來，兩人都選完才一起揭曉。② 按得分表計分，連玩數輪，想辦法令自己爭取最高分數。』

學生畫面計分說明：『計分方法：自己食掉自己那包小食，得 1 分；收到對方分給你的一半，會很開心，得 3 分。把兩項分數加起來，就是這一輪你的得分。』

四格得分表（預設，囚徒困境結構：T=4>R=3>P=1>S=0，且 2R=6>T+S=4）：

| | 同學 B 選 🤝 分一半 | 同學 B 選 😋 自己食 |
|---|---|---|
| 同學 A 選 🤝 分一半 | A 得 3 分，B 得 3 分 | A 得 0 分，B 得 4 分 |
| 同學 A 選 😋 自己食 | A 得 4 分，B 得 0 分 | A 得 1 分，B 得 1 分 |

即時提示只描述本輪發生了什麼（各選了什麼、各得幾分、對應哪一格），並提醒可留意紀錄裏對方之前的選擇；學生畫面不預先揭示合作、一報還一報等結論。紀錄表列出每輪選擇、得分、兩人合計及累計分數。

教學重點（只放在老師說明／`?teacher=1`）：學生在嘗試中自己發現，只顧自己眼前最高分（無論對方選什麼，「自己食」都令自己該輪較高分：對方分一半時 4>3，對方自己食時 1>0），兩人合計未必最高（兩人都自己食合計 2 分，兩人都分一半合計 6 分）；連玩數輪後，對方之前的選擇會影響信任，互相信任、持續分一半（合作），長遠累計往往較高。有組可能自然出現「你上次分我就分、你上次自己食我就自己食」（一報還一報）。這些結論只在全班討論時由老師帶出。只做單輪或連玩數輪，沒有錦標賽或演化長篇，不設個人戰績榜。

**第 5 節　地圖著色戰線**  
學生頁學習目標：我能夠按規則嘗試和調整，找出用最少顏色完成的方法。  
學生頁任務目的：① 為每個區域著色：共用一條邊的兩個區域，顏色要不同；只碰到一個角，不算相鄰。② 把整幅地圖都塗好，就算完成。再試試看，能不能用更少顏色再做一次。  
8 色調色盤，開始不寫「四色定理」、不預先告訴學生「要用幾種顏色」或「這幅最少要幾種」。關卡名稱與「任務目的」只強調規則（共邊不同色、只碰角不算），讓學生透過不斷嘗試找出每幅最少要用幾種顏色。完成後只顯示「你這次用了 N 種」，並鼓勵再試能不能用更少，不會對照最少色數。四色定理與每幅的 χ 只放在老師說明。地圖為完全鋪滿的長方框（無海洋空隙）。區域由細格子合併而成（種子生長，每區連通、大小相近）；格頂點以固定種子輕微抖動（邊框上的點只沿邊框移動，四角不動）。所有邊界拆成「連結點之間的邊界鏈」，每條鏈只平滑一次，相鄰區域的填色 path 由同一條共用鏈（需要時反向）拼成，描邊只畫一次每條鏈，因此無縫隙、無重疊。相鄰＝共用至少一條格邊，只碰一角不算。白點與筆記點放在區域內部遠離邊界的格子中心。部分區域預先填色（白點標記、不可改）作為起點。選顏色後點區域填色，再點同一區同一色可清除；相鄰同色會即時用紅色加粗共用鏈並加上區域紅框，並累計「錯誤」次數。可選計時與「筆記」模式（在區內標記可能的顏色）。支援／基本／挑戰各 3 幅（約 8／15／25 區），另有可選專家層 2 幅（約 28 區，最小觸控不少於約 60px）。載入時自動驗證：鏈拼接閉合、每區連通、鄰接對稱、只碰角不算、預填無衝突且最多四色可解（結果只在主控台與老師說明）。已保留 Safari 地圖高度修正。

**第 6 節　豪賭客（Pig 骰子）**  
學生頁學習目標：我能夠根據可能發生的結果比較風險和得益，判斷甚麼時候應該停。  
學生頁任務目的：① 開始前，和同學一起定下目標分數，也可以定下自己的停手分數。② 輪流擲骰子：可以再擲，或停手把本輪分數放入分數袋。③ 如果擲到 1，本輪分數會全部清掉。④ 誰先到達目標分數就算完成。  
開局前由學生自己設定目標分數（可輸入，範圍 10 至 200，不預先選好建議值；未設定不能開始）。每位玩家可選「我打算本輪到 __ 分就停」或「不設，每次自己決定」（二者都不預選）。達到自己的停手分數時只提醒「已到你定的停手分數」，不強制停手。同機雙人對戰為主，電腦對手只是可選，畫面不會寫出電腦的建議停手數字。紀錄記下每位玩家的停手打算及每輪結果（入袋幾分或擲到 1 清零）。挑戰層讓學生自己輸入兩個停手分數來比較（不預填）。支援層另顯示本輪擲了幾次，並提示「骰子有 6 面，其中 1 面是 1」；基本層一般玩。畫面是兒童遊戲風（骰子、分數袋），不用真錢、不兌換獎品、沒有賭場風格。學生頁不揭示最佳停手點。

## 教師如何調難度

每頁都有「支援／基本／挑戰」按鈕，學生可自選、中途可轉層。

- 第 1 節：支援鎖 +3 與短詞；挑戰可做未知鑰匙（須自己一把一把試）或豬圈小詞。
- 第 2 節：支援全部一人一句；基本兩人題；挑戰互相指稱或出題。
- 第 3 節：支援 3 位 1–4；基本 3 位 0–9；挑戰 4 位或允許重複。提示工具預設全部關閉；支援層可鼓勵開啟 A／B 意思提示和數字排除板，挑戰層建議先不用「揭示一個位置」。
- 第 4 節：支援先 1 輪（可改連玩 3 輪）；基本 1 輪＋再連 5 輪（玩完可再加輪）；挑戰可先口頭約定（仍要各自按藏選擇）或改得分表再玩。
- 第 5 節：支援約 8 區、基本約 15 區、挑戰約 25 區（另有可選專家層約 28 區，最小觸控不少於約 60px）；部分區域預填為起點。名稱與學生頁不透露色數或四色定理。
- 第 6 節：目標分數和停手分數由學生自定（不預填建議值）。支援層顯示本輪擲了幾次並提示骰子有一面是 1；基本層一般玩；挑戰層讓學生輸入兩個停手分數來比較。到達自定停手分數只提醒、不強制。

二人角色建議：操作員、記錄員，中途互換。第 1、3 節建議橫向；其餘直向或橫向均可。

## 已知限制

- **尚未在真實 iPad Safari 上實測觸控。** 教師上課前必須用自己的 iPad 以 Safari 開啟每一頁預演（觸控、橫向／直向、字體大小）。
- 進度只存在該頁記憶體，重新整理會清除；不收集姓名、班別、電郵或相片，亦不開相機／麥克風。
- 地圖為完全鋪滿的長方框；區域由細格子合併，邊界鏈只平滑一次並由相鄰區域共用，因此填色與描邊吻合、無縫隙無重疊。相鄰判斷來自格子上的共用邊（只碰一角不算），載入時自動覆核。
- 第 1 節凱撒不能加密漢字，這是規則本身的限制，不是故障。
- 色覺辨認困難的學生，地圖著色可能需要同伴協助（顏色另有中文名稱）。
- 四色定理、反證法、囚徒困境與風險選擇都只做小學程度的初步認識，不引入形式證明或公式。
- 本資料夾是課堂預覽初稿，不會自行上載到 GitHub。
